# E2E: select region / subject mask and edit non-destructively
# Setup: pnpm dev, album with an uploaded image

1. Open /albums/:albumId/images/:imageId
2. CLICK "✨ Subject" in the canvas toolbar (or click Layers -> "✨ Select subject")
   ASSERT: BiRefNet foreground cutout loads as translucent indigo mask overlay; composer badge displays "Subject · <region>"
3. CLICK Brush (B) or Eraser (E) tool and paint/refine the mask
   ASSERT: mask updates smoothly; clicking "Invert" swaps subject <-> background selection
4. Type prompt ("golden autumn bokeh background") with Mask active and press Enter
   ASSERT: History shows "Region edit · Editing the region…" (2 credits)
5. WAIT for completion
   ASSERT: Editor navigates to branched photo; Compare ("Split wipe", "Side-by-side", "Hold \") reveals only masked area changed
6. Press Cmd/Ctrl+Z (or click "← Parent") -> navigates back to parent branch; Cmd/Ctrl+Shift+Z returns to child
